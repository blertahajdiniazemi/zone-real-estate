1 · Lidhja me GitHub

Tokeni është çelësi i vërtetë. Pa të, askush nuk mund të ndryshojë asgjë.

Si të krijoj një token? (një herë, zgjat 90 ditë)
  1. Hyni në GitHub → foto juaj lart djathtas → Settings.
  2. Poshtë fare në të majtë: Developer settings.
  3. Personal access tokens → Fine-grained tokens → Generate new token.
  4. Emri: zone-admin. Skadimi: 90 ditë.
  5. Repository access → Only select repositories → zgjidhni zone-real-estate.
  6. Permissions → Repository permissions → Contents → vendoseni në Read and write.
  7. Klikoni Generate token dhe kopjoni vlerën që shfaqet.
Rëndësishme: tokeni shfaqet vetëm një herë. Ruajeni diku të sigurt. Mos ia jepni askujt dhe mos e shkruani brenda skedarëve të faqes. Nëse humbet, fshijeni në GitHub dhe krijoni një të ri.
